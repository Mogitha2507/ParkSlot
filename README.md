# ParkSpot - Society Visitor Parking Slot Tracker

A deliberately small Spring Boot + MySQL backend for a college project.

## Software
- Java 21
- Spring Boot 3.5.5
- Maven
- MySQL
- VS Code
- Postman

## Database setup

Open MySQL and run:

```sql
CREATE DATABASE parkspot;
```

Then edit:

`src/main/resources/application.properties`

Replace:

```properties
spring.datasource.password=YOUR_MYSQL_PASSWORD
```

with your MySQL password.

## Run

Open the project folder in VS Code terminal:

```powershell
mvn spring-boot:run
```

Server:

`http://localhost:8080`

## Postman order

### 1. Create a flat

POST `/api/flats`

```json
{
  "flatNumber": "A-101"
}
```

### 2. Create a parking slot

POST `/api/slots`

```json
{
  "slotNumber": "S1"
}
```

Create more slots the same way: S2, S3...

### 3. Vehicle entry

POST `/api/entries`

```json
{
  "vehicleNumber": "TN38AB1234",
  "flatId": 1,
  "slotId": 1
}
```

The service checks whether the slot is already occupied.

### 4. See occupied slots/vehicles

GET `/api/occupied`

### 5. Vehicle exit

PUT `/api/exits/1`

Replace 1 with the visitor vehicle record ID.

This records exit time and frees the slot.

### 6. Daily report

GET `/api/daily-report`

### 7. All slots

GET `/api/slots`

### 8. Simple dashboard

GET `/api/dashboard`

## Important business rules
- An occupied slot cannot be assigned again.
- Exit cannot be recorded before entry.
- A vehicle cannot exit twice.
- Entry and exit times are generated by the service.
- Invalid requests return a simple JSON error.

This project intentionally avoids a frontend, Lombok, DTO layers, mapper classes, and unnecessary folders so that the code is easy to explain.
